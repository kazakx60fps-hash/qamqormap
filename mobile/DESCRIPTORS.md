# Дескрипторлар → экран / функция → тексеру тәсілі

Жобада бөлек дескрипторлар файлы табылған жоқ. Сондықтан критерийлер екі көзден алынды:

* жоба жоспарының **«11. Қабылдау өлшемдері»** бөлімі (`QamqorMap_project_plan.md`) — **Ж1–Ж8**;
* мобильді қосымшаға қойылған тапсырма — **М1–М24**.

Белгілер: **А** — API тесті (`npm test`, түбірлік папка), **Б** — браузердегі сценарий
(`mobile/scripts/e2e-web.mjs`, 390×844 телефон көрінісі, 25 қадам), **С** — сайттың сценарийі
(`scripts/e2e.mjs`, 23 қадам), **Т** — `mobile` тесттері / TypeScript / бандл жинау.
Барлық тексеру 2026-11-04 күні орындалып, сәтті өтті. Тексерілмеген бөліктер ең төменде жазылған.

## Тексерілмегендер (ашық айтамын)

* **Android APK осы ортада жиналмады**: Android SDK жоқ, ал `dl.google.com`, Maven Central және
  `services.gradle.org` желіге жабық. `expo prebuild` сәтті өтті (AndroidManifest-те `kz.qamqormap.app` және
  `usesCleartextTraffic` бар). Android/iOS JS бандлдары (Hermes) сәтті жиналды. APK жинау командалары README-де.
* **Нақты телефонда (Android/iPhone) тексерілген жоқ**: қосымша Expo веб-нұсқасында, телефон көрінісінде
  тексерілді. WebView ішіндегі карта (`QMap.tsx`) веб-нұсқадағы iframe-мен бірдей HTML мен хабар алмасуды
  қолданады, бірақ оның өзі құрылғыда іске қосылған жоқ.
* **OpenStreetMap карта фоны** көрінбеді (ортада интернет жоқ); белгілер, тізім және сүзгілер тексерілді.
* **Windows демо скрипті** (`IskeQosu-Demo.bat`) бұл ортада іске қосылған жоқ (PowerShell жоқ).
