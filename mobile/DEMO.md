# Қорғауға арналған көрсетілім (2–3 минут)

**Дайындық (бір рет, қорғауға дейін):**

1. Компьютерде: `npm run demo:reset`, содан кейін `npm run demo` (Windows: `IskeQosu-Demo.bat`).
2. Терезеде шыққан `Мобильді қосымша үшін API мекенжайы: http://192.168.x.x:3000` мекенжайын жазып алыңыз.
3. Телефонда: `cd mobile && npx expo start` → Expo Go арқылы QR-код (немесе орнатылған APK).
   Қажет болса: Профиль → Сервер мекенжайы → мекенжайды жазып, «Байланысты тексеру».
4. Компьютер браузерінде сайтты ашыңыз: `http://localhost:3000` — қосымшадағы өзгерістер осында көрінеді.

| Уақыт | Әрекет (телефонда) | Не көрсетеміз |
|---|---|---|
| 0:00 | Қосымшаны ашу | Басты экран — карта: қала, «Көмек немесе қала іздеу», үш сүзгі, төменгі панель |
| 0:10 | Жоғарыдағы **RU → EN → KK** | Интерфейс бірден ауысады; таңдалған қала мен сүзгі сақталады |
| 0:20 | Қала батырмасы → іздеуге `Oskemen` → **Астана** | Барлық қала облыс бойынша; латынша іздеу; карта мен статистика жаңарады |
| 0:30 | Панель батырмалары ▲ ▼, «Карта / Тізім» | Панельдің үш күйі |
| 0:40 | «Табиғи апаттар» → картадағы қызғылт сары ромб | 112 ескертуі; «Оқу мысалы», «Тексерілмеген», жаңарту уақыты |
| 0:50 | «Оқиғаны ашу» → байланысты өтініш | Оқиғаның аумағы, дереккөзі, байланысты өтініштер; «Көмек қажет» |
| 1:00 | Профиль → **Демо-кіру: Өтініш иесі** → «+» → өтініш толтыру → «Тексеруге жіберу» | Қала өзі қойылады, картадан нүкте; мәртебе «Тексеруде» |
| 1:20 | Профиль → Шығу → **Демо-кіру: Координатор** → Координатор панелі → өтінішті **Бекіту** | Модерация кезегі; өтініш картада пайда болады |
| 1:35 | Шығу → **Демо-кіру: Ерікті** → өтініш → «Көмектескім келеді» | Мекенжай әзірге жабық |
| 1:50 | Өтініш иесі ретінде кіру → ұсынысты «Орындаушы ретінде таңдау» | Енді еріктіге мекенжай мен телефон ашылады (серверде тексеріледі) |
| 2:05 | Ерікті: «Хат алмасу» → хат; «Жұмысты бастау» → «Көмек орындалды» | Чат; өтініш иесінде оқылмаған белгісі |
| 2:20 | Өтініш иесі: «Нәтижені растау» | Мәртебе «Аяқталды», картадағы статистика +1 |
| 2:35 | Қосымшаны толық жабып, қайта ашу; сайтта сол өтінішті ашу | Кіру мен деректер сақталған (PostgreSQL); сайт сол деректі көрсетеді |

Уақытты үнемдеу үшін рөлдерді екі телефонда (немесе телефон + сайт) қатар ашуға болады.
Көрсетілімнен кейін: `npm run demo:reset`.
